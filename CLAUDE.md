# AI agent entry point

Read [`AGENTS.md`](AGENTS.md) before editing anything. It is the canonical, tool-agnostic
instruction set for Claude and every other coding agent. Then read
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) before making architectural or cross-layer changes.

Use [`scripts/setup-rust.sh`](scripts/setup-rust.sh) when Rust is not installed. Do not duplicate
or weaken the rules in `AGENTS.md`; update that file if shared agent guidance must change.
